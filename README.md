# Smart Notepad

### A lightweight and futuristic Android notepad app built 100% offline using AIDE.  
Write, save, and manage notes smoothly with modern UI — perfect for students and developers!

---

## Features

- Futuristic smooth UI with hybrid HTML + Java  
- 100% AIDE compatible project file (no Android Studio needed)  
- Simple notepad functionality with scroll and save  
- Works fully offline  
- Clean and lightweight — ideal for low-end devices  
- Made with native Android SDK + custom HTML view blending

## Installation

1. Download the latest `.apk` or `.zip` AIDE project [here](#).
2. Extract (if zipped) and open the project in AIDE.
3. Run and enjoy writing smart notes!

---

## How to Use

- Tap to create or edit your notes.  
- Press the save button to keep them locally.  
- UI scrolls smoothly with custom HTML layout.  
- All views are controlled from `MainActivity.java`.
